## Phase Goal

**As an** operator, **I want to** run one local command that turns one real AI-generated image into one
real AI-generated video through the two paid providers this whole product depends on, **so that** I know
the riskiest, least-controllable dependency in the project actually works — with real per-call cost
visible and provider blocks named — before a single hour goes into persistence or interface.

This is the tracer slice: one path, wired end to end, production-quality. `src/providers/image/gemini-image.ts`
and `src/providers/video/veo.ts` are written to survive into Phase 2 unchanged (CONTEXT.md Claude's
Discretion); only the output artifacts (D-06) and the ledger (D-04/D-05) are throwaway.

Purpose: ROADMAP Phase 1 exists because this is "the riskiest, least-proven part of the whole project
(a paid-preview API)". Every criterion in the phase is satisfied or falsified by this one command.

Output: two provider modules, one CLI entry point, one PNG, one MP4, and a printed cost line per call.

Expected spend for this plan: one image call at $0.067 plus one 4-second 720p clip at $0.20 = **$0.267**
against the $3.00 ceiling. If the ledger total after this plan is materially above that, stop and report
it — an unexpected figure is a finding about real pricing, which is exactly what SC-3 asks for.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| smoke-test process -> Google Gemini / Veo API over HTTPS | The secret API key crosses outbound; untrusted, provider-shaped response data crosses inbound and is parsed. |
| provider response -> local filesystem | Response bytes are written to disk as `.png` and `.mp4` without validation beyond size and container signature. |
| process -> stdout and `storage/_smoketest/generic-run.log` | Durable output that may be pasted into an issue or a SUMMARY. The key must never reach it. |
| local operator terminal -> smoke-test CLI | Developer-authored prompts only; no third-party user input reaches a prompt in this phase. |

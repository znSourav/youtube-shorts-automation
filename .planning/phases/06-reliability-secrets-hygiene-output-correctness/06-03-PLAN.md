|----------|-------------|
| Provider download → local filesystem | Where a non-video payload could be written under a `.mp4` name |
| Local filesystem → scene READY status | Where a mislabeled file could be promoted to a usable asset |
| Validation verdict → browser message | Where byte counts, dimensions, and container terminology could leak |
| npm registry → `node_modules` | Where a supply-chain substitution could enter the build |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-SC | Tampering | `mp4box` install via npm | high | mitigate | 06-RESEARCH.md's Package Legitimacy Audit table returned a clean verdict (npm registry, `github.com/gpac/mp4box.js`, 336,673 weekly downloads, BSD-3-Clause, no install script) with zero `[ASSUMED]`/`[SUS]`/`[SLOP]` entries, so no blocking human checkpoint applies. Install is pinned to `2.4.1` and the absence of an install-time script is re-confirmed against the live registry immediately before installing. |
| T-06-09 | Spoofing | A text error body or mislabeled image saved under a `.mp4` name and promoted to READY | high | mitigate | `validateMp4Buffer` checks the container signature at bytes 4 through 8 and requires the parser's ready callback to fire before any scene reaches READY; check-boundaries invariant 10 keeps the READY write unreachable before that call. |
| T-06-10 | Information Disclosure | `Mp4ValidationResult.reason` (byte counts, dimensions, container terms) reaching the browser | medium | mitigate | The reason is passed only to `console.error`; the browser receives the fixed `CORRUPT_VIDEO_MESSAGE` constant, whose content is asserted by test to exclude container, dimension, and path substrings. |
| T-06-11 | Tampering | The new Scene columns widening what `findStoryWithScenes` ships toward the browser | low | accept | The columns are read only by server-side decision code; `get-story-status.ts` (plan 06-04) exposes derived booleans and no raw column value. `listStoriesWithSceneCounts`'s narrow explicit selection is untouched. |
| T-06-12 | Denial of Service | A malformed buffer causing the container parser to hang or exhaust memory | low | accept | Parsing happens on a buffer already fully read into memory and bounded by the downloaded file's own size; the parse is synchronous, wrapped in a try, and the minimum-size and signature pre-filters reject the cheapest garbage before the parser is invoked at all. |

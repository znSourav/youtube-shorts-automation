| Boundary | Description |
|----------|-------------|
| Server Action return value → browser | The only channel from server to client; every string crossing it must be pre-approved plain language |
| `process.env` → provider modules | Where the raw API key lives; must never be read outside a server-only module |
| Provider response → server console | Where `logRawResponse` prints; redaction is the control |
| Working tree → git history | Where `.env.local` must never cross |

- Task 1: one 4-second 720p Veo clip against an **image plan 02-03 already generated** — do not regenerate images for this. Estimated **$0.20**.
- Task 2: one 3-scene Banglish story call, story only, no images, no video (**$0.05**); then one full-scale run at 5 scenes — story (**$0.05**) plus 5 images (**$0.34**) plus one 6-second clip (**$0.30**) — about **$0.69**.

Total for this plan: about **$0.94**, landing the ledger near **$2.45** of $3.00. That headroom is real but thin, which is exactly why D-04 exists. Run each paid step **once**. If a run fails, read the logged raw response and the classified reason before spending again, and reduce scope (fewer scenes, a shorter clip) rather than re-running at full scale. If `checkCeiling` throws, STOP and report — raising `DEV_CEILING_USD` or repointing `LEDGER_PATH` is prohibited.
